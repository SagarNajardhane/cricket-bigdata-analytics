# 🏏 Cricket Match & Player Performance Analytics using Big Data

End-to-end Big Data project using **Hadoop (HDFS + MapReduce)** and **Apache Spark** on **Cricsheet IPL** ball-by-ball data, with an interactive **Streamlit** dashboard.

## Course Outcomes
- **CO1:** HDFS commands & distributed data management
- **CO2:** MapReduce + Spark analytics
- **CO3:** Performance evaluation of big data applications

## Tech Stack
WSL2 Ubuntu · Hadoop 3 · Spark 3 (PySpark) · Python · Streamlit · Plotly · Git/GitHub
